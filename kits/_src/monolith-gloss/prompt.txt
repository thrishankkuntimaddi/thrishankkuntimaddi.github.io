Apply the "Monolith Gloss" theme to this project, using monolith-gloss.css, monolith-gloss.csv and MONOLITH-GLOSS-THEME.md. Follow the rules exactly:
1. Load Inter from Google Fonts, then monolith-gloss.css after the project's own CSS. Put class "gl-root" on <body>. Dark is the default; light is <html class="light"> (or data-theme="light").
2. Surfaces. Monolith base: page, side panels, lists, cards and tables are solid (--bg-base / --bg-surface, gl-card, gl-panel), near-square (3px). Liquid glass only on layers that float over content: menus and popovers (gl-liquid), dialogs (gl-dialog + gl-scrim), toasts (gl-toast), docks and the command palette (gl-liquid gl-liquid--strong). App chrome (top bar, icon rail) uses gl-glass-bar: the glass look without blur. Never put backdrop-filter on a long scrolling list.
3. Map components: buttons → gl-btn (sizes gl-btn--sm / gl-btn--lg); the ONE main action per view → gl-btn gl-btn--primary (gold with a specular top light); quiet actions → gl-btn--ghost; icon-only → gl-icon-btn; inputs → gl-input (search: gl-search wrapper); tabs → gl-tabs + gl-tab; counts → gl-count; page header → gl-page-head + gl-eyebrow + gl-page-title + gl-page-lead; empty states → gl-empty (gl-empty-mark, gl-empty-title, gl-empty-text); big hero titles → gl-display (add gl-sheen for the metallic gold text); empty large areas → gl-ambient (grid + soft aurora).
4. Never write a colour literal in a component. Use var(--accent), var(--text-primary|secondary|muted), var(--bg-base|surface|hover|active|input), var(--border-subtle|default|accent), var(--state-success|warning|danger), var(--gl-accent-soft), var(--gl-accent-line).
5. In light mode --accent is a deeper gold so it passes AA as text; for gold fills use --gl-accent-grad with --gl-on-accent text. Light shadows are warm (rgba(60,44,20,…)), never grey/black.
6. Motion: 150/190/220ms (--gl-dur-1/2/3) with --gl-ease. Hover lift only on cards (gl-card--interactive) and the primary button; a small press-in on buttons. prefers-reduced-motion turns animation off.
7. Copy: sentence case, plain words. Icons 14–18px (lucide or similar), accent colour for marks, currentColor elsewhere. No emoji as UI icons.
8. Layout: page head (eyebrow = where you are, title = the page noun, lead = one sentence), then an optional toolbar, then sections. Must work at 390px, 834/1024px and 1280–1440px, in light and dark.
