Oruinwan

Collaboration app · UI system · Open source

One workspace for every conversation. Channels, DMs, huddles, tasks, notes and AI share one interface, so a team stops jumping between five apps.

  • One interface that adapts from phone, to split view on tablets, to wide desktop. Phones on the web get the same UI as the app, so iPhone users get the full experience in Safari.
  • Designed so context never gets lost: a message becomes a task that points back to it, a call's recap lands in the channel that held it, and @ai works in any chat.
  • 1,091 commits of iteration, with end-to-end tests that check what's actually visible on a phone screen.
  • React 19
  • Tailwind
  • Vite
  • Yjs realtime
  • Socket.IO
  • Capacitor

Expense Tracker

Personal finance · Glass UI · v4.3

Your whole money life in one calm app: expenses, income, bills, budgets, goals, debts with friends and trip splits, in any currency.

  • Quick entry that reads like a text message: type “chai 20 vada 15” and it logs two expenses, each already categorised.
  • One big number up front, how it compares to your budget and a “safe to spend today” figure, instead of charts you have to decode.
  • A soft glass visual language that looks the same as a PWA, on Android (Capacitor) and on desktop (Tauri).

SentinelFlight

3D game UI · Three.js · Space

Fly real rockets through the real sky. I turned dense orbital mechanics into a game anyone can play, with an AI copilot I trained to dodge real debris.

  • Hard data made readable: a launch-window chart, chase, onboard and map cameras, time warp, and a debrief with stars and a score.
  • A Three.js scene of the real tracked catalog. The orbit maths runs in Web Workers, so the interface stays smooth.
  • Under the hood, a Double DQN agent that was 100% safe on 200 held-out scenarios.
  • Three.js
  • WebGL
  • Web Workers
  • JavaScript
  • Python
  • PyTorch

LearnViaNotes

Reading UX · Design system · PWA

A calm, focused interview sheet: 22 subjects and 150 coding problems in four languages. No sign-up wall. Just learn.

  • Notes are structured blocks (callouts, code, tables) drawn by one set of reusable components, effectively a small design system for reading.
  • Read-aloud, a focus timer and spaced repetition, with offline support for anything you've already opened.

03 — Craft

The details I can't stop caring about.

Motion with meaning

Animation should explain where things came from and where they went. I tune every easing curve and respect reduced-motion settings.

Tokens, not hex codes

Colour and type live in design tokens. Change the universe on this page and every component restyles from one source.

Phone first, everywhere after

04 — About

Interfaces are where software meets people. That's my favourite place to work.

I'm Thrishank, a computer science engineer from India. I started in AI and computer vision, but what kept pulling me back was the screen in front of the user: how it looks, how it moves, how it feels the hundredth time you open it.

Now I design and build interfaces end to end, from the first sketch in code to the release on web, Android and desktop. I can also build the backend behind them, so an idea reaches people whole instead of as a mock-up.
